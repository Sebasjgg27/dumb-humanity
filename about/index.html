About the Rebirth Manual

This is an open-source, offline-first knowledge base for restarting human civilization — built in the spirit of the anime Dr. Stone and grounded in the real science of knowledge recovery.

Why this exists

If civilization collapsed, the single most valuable resource would be knowledge: not gold, not machines, but the instructions for making things from scratch. Modern survivors know how to use things but not how to make them. This site is an attempt to close that gap with a practical, ordered technology tree.

The sources

  • Dr. Stone — the staged technology progression (stone → iron → electricity → radio), and the idea that knowledge is an adventure you can re-walk.
  • The InfoPreserver Project (Lifeboat Foundation) — the “Rebuild Ladder” capability levels A0–A5 that organize this site.
  • The Knowledge: How to Rebuild Our World from Scratch by Lewis Dartnell — the scientific method of civilization recovery.
  • Open Source Ecology / Global Village Construction Set — open blueprints for the 50 machines that bootstrap a modern settlement.
  • Survival and bushcraft traditions — the low-tech fundamentals that keep people alive.

How to use it

  1. Start at A0 — water, fire, shelter. The floor is not optional.
  2. Follow prerequisites — every guide lists what you need before it.
  3. Scavenge first — every guide lists what the ruins already provide.
  4. Teach and print — copy the guides, pass them on, and print the critical pages. Paper outlives grids.

The principles

  • Digital is temporary. Print is permanent.
  • Redundancy saves knowledge — three people must know every critical skill.
  • Knowledge compounds — the ladder is faster at every step because the steps before it get easier.

Contribute

This is a work in progress, built incrementally. The content tree is open and structured to grow: every stage, every guide, every salvage list can be extended.
