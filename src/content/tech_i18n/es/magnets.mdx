# Imanes y electromagnetismo

El magnetismo es la mano invisible que hace posible la electricidad — un generador es
literalmente "hacer girar alambre en un campo magnético". Los imanes naturales (magnetita) se
conocían desde la antigüedad; el *electromagneto* (hierro + bobina enrollada + corriente) es el
caballo de batalla de A2 que hace que los generadores y motores sean lo bastante fuertes para ser
útiles.

## Imanes naturales y fabricados

- **Magnetita**: un imán permanente natural — la piedra imán del compás antiguo.
- **Imantación por golpes**: frota una aguja de acero repetidamente en una dirección con un
  imán → imantación permanente (la aguja del compás).
- **Electromagneto**: una bobina de alambre de cobre alrededor de un núcleo de hierro. Corriente
  encendida → imán fuerte. Corriente apagada → no es imán. Este es el campo de fuerza controlable
  de A2.

## El compás (la navegación abre el comercio)

Una aguja imantada flotando en un corcho o pivotando sobre un alfiler apunta al norte. Del compás
surgen la navegación, los mapas y el comercio a larga distancia — la columna vertebral logística de
A2/A3.
(Este es uno de los dispositivos de mayor valor por gramo de toda la escalera.)

## Electromagneto → el corazón del generador

1. Enrolla una bobina de [alambre tirado](../wire_drawing/) sobre un núcleo de hierro.
2. El hierro concentra el campo magnético miles de veces (permeabilidad magnética relativa).
3. Generadores autoexcitados: un pequeño imán permanente "descarga" la bobina, estableciendo un
   campo electromagnético que luego se alimenta a sí mismo — arranque de corriente automático.
4. La misma física invertida = el **motor eléctrico**.

## Escalera de aplicaciones

| Dispositivo  | Uso                                          |
| ------------ | -------------------------------------------- |
| Compás       | Navegación, cartografía                      |
| Electromagneto | Levantar chatarra, clasificar metales, embragues |
| Generador    | [Electricidad](../electricity_generator/)    |
| Motor        | Movimiento a partir de corriente (molinos, bombas) |
