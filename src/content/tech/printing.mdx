# Printing: The Knowledge Multiplier

Before printing, knowledge was the property of scribes — one copy at a time, and
a lost manuscript was a lost civilization. Printing turns knowledge into a *multiplier*:
one corrected guide can be copied by the hundred. On this ladder, printing is how the
rebuild manual itself gets distributed.

## Movable type (the A2-rebuildable way)

1. **Type**: cast letters in lead/bronze from brass or clay *matrices* (molds).
   [Metrology](/dumb-humanity/tech/metrology) gives you uniform height — mixed-height
   type won't print evenly.
2. **Composition**: arrange type in a line, lock rows in a frame (the chase).
3. **Ink**: lampblack (soot) ground into linseed/vegetable oil — the printer's ink.
4. **Press**: a screw press (wood, then iron) presses the inked type onto the sheet.
5. **The eternal copy**: the same set of type prints page after page after page.

## Why this is a civilization-scale event

- **Textbook duplication**: the ladder's knowledge gets printed, not memorized.
- **Standardization**: every copy identical — errors can't silently drift.
- **Instruction at scale**: a printed seed-calendar, soap recipe, or furnace plan
  reaches every household.

## Sequence of what to print first

1. Survival essentials (water, fire, hygiene).
2. Agricultural calendar + seed rules.
3. The medical basics.
4. A2 build guides (charcoal, iron, steam, generator).
5. A "how we did it" community record.
