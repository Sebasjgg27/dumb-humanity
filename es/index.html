Principios de diseño

Construido para la permanencia

  • Offline-first

    Cada artículo es HTML estático. Descarga el ZIP y toda la biblioteca funciona sin electricidad, red ni servidores.

  • La impresión es permanente

    Las redes eléctricas fallan. Las pantallas mueren. El papel sobrevive a ambas.

  • Validado y reproducible

    Cada procedimiento enumera materiales, herramientas, pasos y la ciencia detrás — reproducible con tecnología disponible progresivamente.

Misión

El Proyecto de Recuperación Civilizacional preserva el conocimiento operativo de la humanidad — las instrucciones para hacerlo todo de nuevo — en un archivo offline-first, listo para imprimir. No es un sitio web. Es una copia de seguridad de la civilización.
