Mission

Le Projet de Récupération Civilisationnelle préserve les connaissances opérationnelles de l'humanité — les instructions pour tout refaire — dans une archive hors ligne, prête à imprimer. Ce n'est pas un site web. C'est une copie de sauvegarde de la civilisation.
