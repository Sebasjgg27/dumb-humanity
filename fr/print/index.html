Conseils d'impression

  • Qualité du papier : le papier sans acide dure des décennies.
  • Encre : le toner laser est plus résistant à l'eau.
  • Laminage : pour les pages utilisées à l'extérieur.
  • Reproduction : un photocopieur est une technologie à préserver.
  • Distribution : gardez un jeu master scellé.

Mission

Le Projet de Récupération Civilisationnelle préserve les connaissances opérationnelles de l'humanité — les instructions pour tout refaire — dans une archive hors ligne, prête à imprimer. Ce n'est pas un site web. C'est une copie de sauvegarde de la civilisation.
